# Thinking Toolkit

A comprehensive collection of **25 interactive mental models and thinking frameworks** for ATLAS Face, inspired by [untools.co](https://untools.co).

## Tools Included

### Decision Making (10)
- **Six Thinking Hats** — Examine decisions from six colored perspectives
- **Eisenhower Matrix** — Prioritize by urgency and importance (2×2 grid)
- **Decision Matrix** — Score options against weighted criteria
- **Impact-Effort Matrix** — Prioritize by weighing impact against effort
- **Second-Order Thinking** — Trace the chain of consequences (1st → 2nd → 3rd order)
- **OODA Loop** — Observe → Orient → Decide → Act
- **Ladder of Inference** — Avoid jumping to conclusions
- **Hard Choice Model** — Classify what kind of decision you're making
- **Cynefin Framework** — Classify situations into 5 domains
- **Confidence → Speed vs Quality** — Trade-off slider

### Problem Solving (7)
- **Ishikawa Diagram** — Root cause analysis by category (fishbone)
- **Abstraction Laddering** — Reframe problems at different abstraction levels
- **Inversion** — Think about what to avoid, then reverse it
- **Issue Trees (MECE)** — Decompose into mutually exclusive branches
- **Zwicky Box** — Morphological analysis for creative solutions
- **Conflict Resolution Diagram** — Find win-win solutions (Evaporating Cloud)
- **Productive Thinking Model** — 6-step creative problem solving

### Systems Thinking (5)
- **Iceberg Model** — Uncover root causes beneath surface events
- **Connection Circles** — Map relationships and feedback loops
- **Concept Map** — Visualize relationships between concepts
- **Balancing Feedback Loop** — Understand stability mechanisms
- **Reinforcing Feedback Loop** — Understand exponential change forces

### Communication (2)
- **Minto Pyramid** — Structure arguments with conclusion-first approach
- **Situation-Behavior-Impact** — Give clear, non-judgmental feedback

## Features

- **AI Assistance** — Every tool has an AI button that auto-fills using your Groq API key
- **Card Export** — Export any tool's output as study cards to your current topic
- **Interactive UI** — Editable lists, grids, sliders, and structured inputs
- **Keyboard Shortcut** — `Alt+T` to open instantly
- **Searchable** — Find tools by name, description, or category

## Installation

Install from the ATLAS Face Marketplace, or manually:
1. Open ATLAS Face
2. Go to **Marketplace** (puzzle piece icon)
3. Find **Thinking Toolkit** and click **Install**

## Requirements

- ATLAS Face v0.2.0+
- Groq API key (for AI features — set in Settings)
